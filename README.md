# react-native-in-app-update

Seamless in-app update flow for React Native: Google Play In-App Updates on Android and App Store version checking on iOS

## Installation


```sh
npm install react-native-in-app-update
```


## Usage


```js
import { multiply } from 'react-native-in-app-update';

// ...

const result = multiply(3, 7);
```
